# PequeMundos · Repositorio Web Infantil

Repositorio académico orientado a proyectos de la Licenciatura en Educación Infantil.

## Incluye

- Estética infantil inspirada en PequeAventuras.
- Enlaces repetidos consolidados en una sola tarjeta.
- Autorías agrupadas cuando el enlace corresponde a un trabajo grupal.
- Información editable en `assets/js/proyectos.js`.

## Publicación

Suba esta carpeta a GitHub y active GitHub Pages.
